# 우리 동네 꼬마 놀이터 (kid-festival)

미취학 아동을 위한 나들이·행사 정보와 학습 콘텐츠(그림동화, 영어·수학·한글 학습 페이지)를 모은 정적 웹사이트입니다.
빌드 과정 없이 `index.html`과 `assets/data/festivals.js`(행사 데이터 1차 출처) 등 정적 파일로 동작합니다.

## 콘텐츠 성격

- 행사 정보(`assets/data/festivals.js`)는 각 행사 공식 홈페이지를 링크로 안내하는 사실 정보이며, 상표·행사명·캐릭터명의
  권리는 해당 권리자에게 있습니다.
- 그림동화 삽화(`assets/images/*`)와 이야기 글은 이 사이트를 위해 직접 제작한 원본 창작물입니다. 무단 복제·재배포·재사용을
  금합니다.

## 기술 스택

- 빌드 없는 정적 HTML/CSS/JS, GitHub Pages(main 브랜치) 배포
- 폰트는 Google Fonts CDN(Jua, Gaegu 등)만 사용

## 안내 문구

본 사이트는 정보 공유 목적의 비영리 제공입니다. 무단 복제를 금합니다. 상표·행사명·장소명의 권리는 해당 권리자에게 있습니다.
