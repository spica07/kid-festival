## 2. 탭 전환 흐름 (핵심 인터랙션)

메인은 페이지 새로고침 없이 **iframe 표시/숨김**으로 코너를 전환한다.

```mermaid
flowchart TD
    A["사용자가 상단 탭 클릭"] --> B{"더보기(⋯)<br/>메뉴인가?"}
    B -- 예 --> C["드롭다운 펼침<br/>aria-expanded=true"]
    C --> D["드롭다운 내 항목 선택"]
    B -- 아니오 --> D
    D --> E["showSiteTab(target) 호출"]
    E --> F["모든 iframe에 .hidden 부여"]
    F --> G["대상 iframe의 .hidden 제거"]
    G --> H{"최초 표시?<br/>(lazy iframe)"}
    H -- 예 --> I["iframe src 로드"]
    H -- 아니오 --> J["이미 로드됨 → 즉시 표시"]
    I --> K["해당 코너 화면 노출"]
    J --> K
```

## 3. 주요 시나리오별 흐름

### 3.1 [부모] 주말 나들이 찾기 — 김서연

```mermaid
flowchart LR
    S1["메인 진입<br/>(기본:동네 축제)"] --> S2["이번 달 행사 목록 확인"]
    S2 --> S3["관심 행사 상세 확인"]
    S3 --> S4{"가 볼 만한가?"}
    S4 -- 예 --> S5["공식 홈페이지에서<br/>일정·예약 재확인"]
    S4 -- 아니오 --> S2
    S5 --> S6["주말 계획 완료 ✅"]
```

### 3.2 [부모+아이] 영어 학습 진행 — 이하준

```mermaid
flowchart TD
    L1["🔤 영어 탭 진입"] --> L2["허브에서 캐릭터 선택<br/>(전체 진행률 확인)"]
    L2 --> L3["코스의 Day 목록 표시"]
    L3 --> L4["오늘의 Day 학습 진행"]
    L4 --> L5["완료 체크 ✅"]
    L5 --> L6["localStorage 저장"]
    L6 --> L7["진행률 바 갱신<br/>(코스/전체)"]
    L7 --> L8{"계속 할까?"}
    L8 -- 예 --> L4
    L8 -- 아니오 --> L9["다음 방문 시<br/>진행 상황 복원"]
```

### 3.3 [아이] 그림동화 읽기


## 4. 진행 상황 저장 상태 흐름

```mermaid
stateDiagram-v2
    [*] --> 신규방문
    신규방문 --> 학습중 : Day 진행
    학습중 --> 저장됨 : 완료 체크 → localStorage
    저장됨 --> 복원됨 : 재방문(같은 기기)
    복원됨 --> 학습중 : 이어서 진행
    저장됨 --> 초기화 : 사이트 데이터 삭제 / 시크릿 모드
    초기화 --> 신규방문
```

## 5. 인터랙션 원칙 (페르소나 반영)

| 원칙 | 적용 |
|------|------|
| **3-클릭 이내 도달** | 메인 → 코너 → 콘텐츠. 자주 쓰는 메뉴는 탭, 나머지는 더보기로 분리 |
| **새로고침 없는 전환** | iframe show/hide로 컨텍스트 유지, 빠른 체감 속도 |
| **즉각 피드백** | 완료 체크 시 진행률 바 즉시 반영 (아이 성취감) |
| **이어하기** | localStorage로 진행 상황 자동 복원 (재방문 동기) |
| **안전한 폴백** | 자식 페이지 단독 진입 시 메인으로 유도 |
| **큰 터치 타깃** | 아이가 부모 기기로 직접 조작 가능하도록 |
