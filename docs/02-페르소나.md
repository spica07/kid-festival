# 페르소나 — 우리 동네 꼬마 놀이터

| 항목 | 내용 |
|------|------|
| 문서명 | 사용자 페르소나 정의서 |
| 버전 | v1.0 |
| 작성일 | 2026-06-04 |

서비스의 핵심 의사결정자는 **부모**이며, 실제 콘텐츠 소비자는 **아이**다. 부모 페르소나 2종, 아이 페르소나 1종을 정의한다.

---

## 페르소나 1 — 김서연 (주 페르소나 · 일하는 엄마)

> "주말에 애 데리고 어디 갈지 매번 검색하느라 지쳐요. 한 군데서 다 보면 좋겠어요."

| 항목 | 내용 |
|------|------|
| 나이 / 거주 | 35세 / 경기 성남 |
| 가족 | 만 6세 딸, 맞벌이 부부 |
| 직업 | 회사원 (주 5일 근무) |
| 기기 | **스마트폰 중심**, 출퇴근·자투리 시간에 검색 |
| 디지털 역량 | 중상 — 앱·웹 능숙하지만 시간이 없음 |

### 목표 (Goals)
- 주말 나들이 후보를 **빠르게** 찾고 싶다 (이번 주말 갈 만한 곳)
- 집에서 아이와 할 **짧은 학습 놀이**가 필요하다
- 정보를 여기저기 검색하지 않고 **한 화면**에서 보고 싶다

### 불편 / 고충 (Pain Points)
- 어린이 행사 정보가 블로그·카페·기관 사이트에 흩어져 있음
- 광고·가입을 요구하는 사이트에 피로감
- 학습 앱은 결제·계정이 번거로움

### 니즈 (Needs)
- 지역(서울·경기·인천) + 월별로 정리된 **나들이 달력**
- 로그인 없이 바로 쓰는 **간편함**
- 모바일에서 한 손으로 탐색 가능한 UI

### 주요 이용 시나리오
1. 퇴근길 지하철에서 '동네 축제' 탭으로 이번 달 행사 확인 → 주말 계획
2. 자기 전 아이와 '그림동화' 한 편 읽기
3. 주말 오전 아이와 '영어 놀이' Day 진행 → 진행률 체크

## 페르소나 2 — 박지훈 (부 페르소나 · 교육 관심 아빠)

> "지금부터 뭘 어떻게 해줘야 할지, 큰 그림이 궁금해요."

| 항목 | 내용 |
|------|------|
| 나이 / 거주 | 38세 / 서울 마포 |
| 가족 | 만 7세 아들 (예비 초등) |
| 직업 | 프리랜서 (재택 비중 높음) |
| 기기 | **태블릿 · 노트북** 주로 사용 |
| 디지털 역량 | 상 — 정보 탐색·비교를 즐김 |

### 목표 (Goals)
- 취학 전 **학습 로드맵**과 진학 경로를 미리 파악
- 아이 수준에 맞는 **체계적 학습 코스**를 꾸준히 진행
- 학습 진행 상황을 추적하고 싶다

### 불편 / 고충 (Pain Points)
- 사교육 정보는 많지만 가정에서 시작할 기준이 모호함
- 진학 경로(과학고·의대·아이비리그 등) 비교 자료가 단편적
- 아이가 어디까지 했는지 기억하기 어려움

### 니즈 (Needs)
- **진학 로드맵** 비교 및 **학습 가이드**
- **30일 단위** 구조화된 코스와 **진행률 시각화**
- 한 번 진행한 내용이 **이어서 저장**되는 경험

### 주요 이용 시나리오
1. 태블릿으로 '진학 로드맵'에서 경로별 비교 열람
2. '수학 사고력' 코스를 골라 Day 단위로 진행
3. 허브의 전체 진행률 바로 아이 학습량 점검

## 페르소나 3 — 이하준 (사용 페르소나 · 만 6세 아이)

> "토끼 선생님이랑 영어 할래! 별 모으는 거 재밌어!"

| 항목 | 내용 |
|------|------|
| 나이 | 만 6세 (미취학) |
| 특징 | 글을 조금 읽고, 그림·캐릭터·소리에 반응 |
| 기기 사용 | 부모와 **함께**, 부모 스마트폰/태블릿 |
| 집중 시간 | 짧음 (10~15분), 재미가 없으면 금방 이탈 |

### 목표 (Goals)
- **좋아하는 캐릭터**(동물 선생님)와 놀듯이 학습
- 동화를 **그림과 함께** 보고 듣기
- 잘했을 때 **칭찬·완료 표시**로 성취감 느끼기

### 불편 / 고충 (Pain Points)
- 글자만 많으면 흥미를 잃음
- 버튼이 작거나 복잡하면 혼자 조작이 어려움

### 니즈 (Needs)
- 큰 버튼, 큰 글씨, 친근한 이모지·캐릭터
- 한 번에 하나의 명확한 행동(다음 장, 완료 체크)
- 즉각적인 시각 피드백(진행 바, 완료 ✅)

### 디자인 시사점
- **터치 타깃 충분히 크게**, 색·이모지로 직관적 안내
- 한 화면에 핵심 행동 1~2개로 단순화
- 캐릭터 중심 동기부여(영어 6캐릭터, 별/배지 등)

## 페르소나 우선순위 요약

| 우선순위 | 페르소나 | 설계 시 핵심 고려 |
|:---:|------|------|
| 1 (주) | 김서연 (일하는 엄마) | 모바일·빠른 탐색·로그인 없는 간편함 |
| 2 (부) | 박지훈 (교육 아빠) | 로드맵·체계적 코스·진행률 추적 |

> 모든 화면 결정은 **"부모가 빠르게 고르고, 아이가 쉽게 따라 한다"**는 원칙을 우선한다.
