# 화면 설계서 — 우리 동네 꼬마 놀이터

| 항목 | 내용 |
|------|------|
| 문서명 | 화면 설계서 (Wireframe / Screen Spec) |
| 버전 | v1.0 |
| 작성일 | 2026-06-04 |

> 와이어프레임은 텍스트(ASCII) 기준이며, 실제 구현은 `assets/css`의 스타일을 따른다. 디자인 톤은 **파스텔 보라(#6B5B95 계열) + 둥근 카드 + 이모지** 중심의 따뜻한 어린이 친화 스타일.

---

## 0. 공통 디자인 가이드

| 요소 | 규격 |
|------|------|
| 기본 언어 | 한국어 (`lang="ko"`) |
| 주요 색상 | 보라 `#4A3F6B`·`#6B5B95`, 배경 파스텔, 포인트 그라데이션 |
| 카드 | `border-radius: 18~22px`, 연보라 테두리 `#F3EEFA`, 부드러운 그림자 |
| 폰트 | 시스템 + 일부 `Jua`(구글폰트, 학습 허브) |
| 반응형 | ≤600px 모바일 1열, 그 이상 멀티 컬럼(`auto-fill minmax`) |
| 접근성 | `aria-label`, `aria-expanded`, `aria-haspopup`, 키보드 포커스 |
| 보안 | 모든 페이지 CSP 메타 적용 |
| 장식 | 떠다니는 이모지(🎈⭐🌈🎀🦋🌸) 플로팅 요소 |

## 1. 메인 / 상단 탭바 (`index.html`)

```
┌───────────────────────────────────────────────────────────┐
│  [동네 축제] [그림동화] [엄마 힐링] [⋯]   🔤  🔢  가  ℹ️   │  ← tab-bar (sticky)
├───────────────────────────────────────────────────────────┤
│                                                             │
│                                                             │
│            ┌───────────────────────────────┐                │
│            │                               │                │
│            │      활성 코너 (iframe)        │                │
│            │   기본: pages/family/          │                │
│            │        kid-festival.html       │                │
│            │                               │                │
│            └───────────────────────────────┘                │
│                                                             │
├───────────────────────────────────────────────────────────┤
│ © 2026 우리 동네 꼬마 놀이터 · 무단 복제 금지 · 정보 공유…  │  ← site-notice
└───────────────────────────────────────────────────────────┘

  [⋯] 클릭 시 드롭다운:
      ┌────────────────┐
      │ 📚 학습 가이드  │
      │ 🗺️ 진학 로드맵  │
      │ 🏆 공모전       │
      └────────────────┘
```

| 구성 | 설명 |
|------|------|
| tab-bar | 텍스트 탭 3개 + 더보기(⋯) + 아이콘 탭 4개. 활성 탭 `.active` 강조 |
| 더보기 | `more-dropdown`, `aria-expanded` 토글, 외부 클릭 시 닫힘 |
| frame-wrap | 9개 iframe 중 하나만 표시(`.hidden` 토글), 축제 외 `loading="lazy"` |
| site-notice | 저작권·정보 공유 목적 고지 (하단 고정) |

## 4. 학습 허브 (영어 예시 · `english-hub.html`)

```
┌───────────────────────────────────────────────┐
│  🎒 6세 영어 첫걸음                              │
│  영어 친구들과 30일 영어                         │
│  좋아하는 동물 선생님을 골라서 시작해요! 🐾      │  ← hero
├───────────────────────────────────────────────┤
│ 🏆 전체 진행 [▓▓▓░░░░░░░]   12 / 180일          │  ← total-bar
├───────────────────────────────────────────────┤
│ [✅ 완료한 과정 보이기]            ← grid-toolbar│
├───────────────────────────────────────────────┤
│ ┌──────┐ ┌──────┐ ┌──────┐                     │
│ │🐰 토끼│ │🐶 강아지│ │🦉 부엉이│  …            │  ← 캐릭터 코스 카드
│ │30일   │ │30일    │ │30일     │                │   (코스별 진행률)
│ └──────┘ └──────┘ └──────┘                     │
├───────────────────────────────────────────────┤
```

| 구성 | 설명 |
|------|------|
| total-bar | 전체 진행률(완료일/총 180일) 시각화 |

| 토글 | 완료 과정 보이기/숨기기 |
| 수학/한글 | 동일 패턴(`math-hub`, `korean-hub`)으로 영역별 코스 카드 구성 |

## 5. 학습 코스 / Day 화면 (영어·수학·한글 공통 패턴)

```
┌───────────────────────────────────────────────┐
│  ← 허브로     캐릭터/코스명     [▓▓▓░] 진행률    │
├───────────────────────────────────────────────┤
│  Day 12                                         │
│  ┌─────────────────────────────────────────┐   │
│  │      오늘의 학습 콘텐츠 (그림·단어·       │   │
│  │      문장·활동 등 — 데이터 기반)          │   │
│  └─────────────────────────────────────────┘   │
│                                                 │
│  [ ◀ 이전 Day ]   [ ✅ 완료 ]   [ 다음 Day ▶ ]  │
└───────────────────────────────────────────────┘
```

| 구성 | 설명 |
|------|------|
| 콘텐츠 | `assets/data/*.js`(예: `english-30days.js`) 기반 일자 단위 렌더 |
| 완료 | 체크 시 `localStorage` 저장 → 허브 진행률 반영 |
| 내비 | 이전/다음 Day 이동, 허브 복귀 |

## 6. 그림동화 리더 (`story-reader`)

```
┌───────────────────────────────────────────────┐
│   ← 동화 목록            제목 / 1 · 2 · 3 …      │
├───────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────┐   │
│ │            (삽화 / 장면 이미지)            │   │
│ ├─────────────────────────────────────────┤   │
│ │  본문 텍스트 (한 페이지 = 한 장면)        │   │
│ │  "대사 / 강조 문장"                       │   │
│ └─────────────────────────────────────────┘   │
│        [ ◀ 이전 ]        [ 다음 ▶ ]            │
└───────────────────────────────────────────────┘
```

| 구성 | 설명 |
|------|------|
| 데이터 | `story-reader.js`의 스토리별 `pages` 배열(제목·본문·대사) |
| 스토리 | 우주·바다·공룡·기차·씨앗정원·소방차·벌레탐정 등 8종 |

## 9. 반응형 규칙

| 화면폭 | 동작 |
|------|------|
| ≤ 600px (모바일) | 카드 그리드 **1열**, hero/안내 폰트 축소, 탭바 가로 스크롤 가능 |
| 601~900px (태블릿) | 카드 2~3열(`auto-fill minmax(240px,1fr)`) |
| > 900px (데스크톱) | 콘텐츠 최대폭 제한(약 820px 컨테이너), 다열 그리드 |
