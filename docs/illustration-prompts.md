# 그림동화 수채화 삽화 — 생성 프롬프트 시트 (신규 20편 · 200장)

기존 동화 삽화(예: `bug-detective-story`, `swim-turtle-story`)의 **전통 수채화 화풍**에 맞춰 새 동화 20편의 삽화를 생성하기 위한 프롬프트 모음입니다.

## 사용법
**최종 프롬프트 = [공통 스타일 프리셋] + [동화별 주인공 설정] + [장면 프롬프트]** 를 이어 붙여서 이미지 생성 도구에 입력하세요.
- 같은 동화 10장은 **주인공 설정을 동일하게 유지**해 캐릭터 일관성을 확보합니다.
- 파일명은 `<slug>-story-01.png` ~ `-10.png` (01 = 표지). 생성 후 같은 이름으로 `assets/images/`에 넣으면 사이트에 바로 반영됩니다.

## 공통 스타일 프리셋 (모든 프롬프트 앞에 붙이기)
- **EN:** `Traditional transparent watercolor children's picture-book illustration, soft wet-on-wet washes, visible paper grain, delicate ink linework, warm natural light, gentle cozy lyrical storybook mood, soft edges, full-bleed, 16:10 horizontal composition`
- **KO:** 전통 투명 수채화 그림책 일러스트, 부드러운 물 번짐, 종이 질감, 섬세한 펜선, 따뜻한 자연광, 포근하고 서정적인 동화 분위기, 부드러운 가장자리, 풀블리드, 16:10 가로 구도

## 기술 사양
- **비율:** 16:10 가로 (예: 1600×1000 또는 1200×750). 표지/장면 모두 동일.
- **Negative prompt (EN):** `text, letters, words, watermark, signature, harsh digital outline, 3D render, photorealistic, flat vector, neon colors, distorted hands, extra limbs`
- **공통 캐릭터 톤:** 둥근 얼굴, 큰 눈, 발그레한 볼, 따뜻한 표정. 동물 주인공은 의인화하되 과하지 않게(자연스러운 동물 형태 + 다정한 눈빛).
